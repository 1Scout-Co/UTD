## Đã làm

- **16 ngôn ngữ**, đủ như yêu cầu, không bớt: vi (VN, nguồn), en (US), zh-CN (CN), zh-TW (TW), ja (JP), ko (KR),
  th (TH), id (ID), hi (IN), es (ES), pt-BR (BR), fr (FR), de (DE), ru (RU), tr (TR), ar (SA, RTL).
  Danh sách duy nhất: `src/shared/i18n/languages.ts`.
- **Thư viện i18n: tự viết, không thêm gói** (`src/shared/i18n/i18n.tsx`, ~150 dòng): `t(khoá, biến)`,
  `tx(khoá, {tên: <code>…</code>})` cho câu có thành phần React, `lookup()` cho khoá ghép lúc chạy,
  `errorText(code, message)` cho lỗi Rust, `useLanguage()`. Lý do: i18next + react-i18next nặng ~15 kB gzip,
  trong khi app chỉ cần tra khoá phẳng + số nhiều (`Intl.PluralRules`); JS chỉ tăng ~2 kB.
- **Khoá phẳng `nhóm.tên`** trong `src/shared/i18n/locales/<mã>.json`; `vi.json` là nguồn. Kiểu `MessageKey`
  lấy từ vi.json ⇒ gõ sai khoá là lỗi `tsc`. Số nhiều: `khoá#one`, `khoá#other`… (vi chỉ có `#other`; ru cần
  one/few/many/other, ar cần đủ 6 dạng), gọi `t("table.count", { count })`.
- **Tải lười**: mỗi file dịch là một tệp `.json` trong `dist/assets` (`import.meta.glob(..., { query: "?url" })`),
  chỉ `fetch` ngôn ngữ đang dùng (+ en làm dự phòng khi thiếu khoá). Không nằm trong JS nên không cộng vào
  trần 200 kB của `.size-limit.json` (size-limit cộng mọi `dist/assets/*.js`, tách chunk JS không giúp được).
  Đo: JS **170,4 kB** gzip (trước ~168 kB), CSS 15,1 kB. Mỗi file dịch ~6–8 kB gzip.
- **Cờ SVG**: 16 file 3:2 chép nguyên từ country-flag-icons 1.6.20 (MIT; `src/shared/i18n/flags/LICENSE`, có ghi
  trong `NOTICE`), không cài gói (exports của gói không cho import thẳng file .svg, và gói có 250+ cờ).
  `?url&no-inline`: mỗi cờ là tệp riêng (tổng ~11 kB), chỉ tải khi mở danh sách ngôn ngữ.
- **Chọn ngôn ngữ**: lần đầu theo `navigator.languages` (WebView2 = ngôn ngữ Windows): zh-HK/MO/Hant ⇒ zh-TW,
  pt-* ⇒ pt-BR, `in` ⇒ id, không khớp ⇒ English. Cài đặt → mục **Ngôn ngữ** (đầu hộp thoại): menu cờ + tên bản
  địa, áp ngay (cả hộp Cài đặt đang mở), lưu bền trong bảng `settings` của journal (khoá `ui_language`, lệnh
  `get_ui_language`/`set_ui_language` ở `src-tauri/src/language.rs`); bản xem trước trên trình duyệt dùng
  localStorage `utd.language`. Chưa chọn lần nào thì không lưu gì ⇒ đổi ngôn ngữ Windows là app đổi theo.
- **Số, dung lượng, tốc độ, ngày, thời gian còn lại** qua Intl (`src/shared/i18n/format.ts`): "19,4 GB" (vi),
  "19.4 GB" (en), "19,4 Go" (fr), "19,4 ГБ" (ru), "MB/giây" (vi). `ar` dùng locale `ar` (không phải `ar-SA`, vì
  ar-SA đổi ngày sang lịch Hijri); `th-TH` giữ lịch Phật giáo như Windows tiếng Thái.
- **Lỗi từ Rust dịch theo mã**: `errorText(code, message)` tra `err.<code>`; `http.<số>` lạ dùng chung
  `err.http` ("HTTP {status}"); không có khoá ⇒ hiện câu gốc. Đã có câu cho mọi mã task hiện có (59 mã, script
  quét Rust tự kiểm). Chẩn đoán (Doctor) chuyển sang bảng `REPORTS` + khoá `doctor.<id>.title/summary/steps`.
  Nhãn định dạng media (Rust `media/probe.rs` đặt tiếng Việt) dịch theo `id` ổn định (`best`, `1080`,

## Thêm chuỗi mới (cho người sau)

1. Viết câu tiếng Việt vào `src/shared/i18n/locales/vi.json` với khoá `nhóm.tên` (đặt cạnh nhóm cùng màn).
2. Trong code: `import { t } from "@/shared/i18n/i18n"` rồi `t("nhóm.tên")`; có biến thì `{tên}` trong câu và
   `t("khoá", { tên })`; có thành phần React (`<code>`, chữ đậm) thì `tx("khoá", { tên: <code>…</code> })`;
   đếm số lượng thì khoá `nhóm.tên#other` + `t("nhóm.tên", { count })`.
3. Thêm cùng khoá vào **15 file còn lại** (dịch tự nhiên, ngắn, cùng thuật ngữ; ngôn ngữ có số nhiều thì đủ các
   dạng `#one/#few/#many/#other`… như script báo). Mẹo: nhờ AI dịch theo vi.json + en.json, giữ nguyên `{…}`.
4. Chạy `pnpm lint` (gồm `i18n:check`): báo thiếu/thừa khoá, sai chỗ trống, chuỗi Việt viết cứng.
5. Lỗi mới từ Rust: đặt `code` ổn định (`nhóm.tên`) cho `TaskError` và thêm `err.<code>` vào mọi file dịch —
   script quét Rust sẽ báo nếu quên. Không cần dịch câu `message` trong Rust.
6. Nhãn không đổi giữa các ngôn ngữ (tên riêng, `URL`, `SHA-256`…) viết thẳng được; chỉ chữ tiếng Việt bị chặn.

Thêm ngôn ngữ mới: một dòng trong `languages.ts` + `locales/<mã>.json` + cờ `flags/<XX>.svg` (chép từ
country-flag-icons 3x2) + `extensions/{chromium,firefox}/_locales/<mã_chrome>/messages.json` + mã trong
`EXTENSION_LOCALES` (`browser_integration.rs`) + ngôn ngữ NSIS nếu Tauri có. Script báo cái nào còn thiếu.

## Việc còn lại / chưa làm

- **Lỗi của lệnh (`Err(String)`) vẫn là câu tiếng Việt gốc** ở mọi ngôn ngữ: kiểm thư mục tải (`commands.rs`),
  đổi tên/di chuyển/xoá file (`files.rs`), Phân tích media (`media/probe.rs`), tải yt-dlp/ffmpeg
  (`media/install.rs`), cập nhật (`updater.rs`), tích hợp trình duyệt. Chúng không có mã nên giao diện chưa dịch
  được. Đề xuất (sau khi ghép các nhánh song song, vì các file này đang bị phiên 2/3/5/6 sửa): lệnh trả
  `{ code, message }` (hoặc tiền tố `mã: câu` như `media_page:`), giao diện dùng `errorText`.
- **Native host chưa gửi mã lỗi**: tiện ích đổi 6 câu tiếng Việt cố định của host (UTD chưa chạy, không phản
  hồi…) sang chữ của tiện ích bằng so khớp nguyên câu (`HOST_TEXT` trong `background.js`); câu khác hiện nguyên.
  Nên thêm `code` vào `HostResponse` (`native_host.rs`) — để sau phiên macOS vì phiên đó đang sửa file này.
- Câu có số liệu riêng trong Rust (vd. `disk.full` "cần khoảng N MB") khi dịch theo mã mất con số.
- Nhãn giao diện trình duyệt trong hướng dẫn cài tiện ích ("Developer mode", "Load unpacked"…): một số ngôn ngữ
  để tiếng Anh vì chưa chắc chữ bản địa của Chrome/Firefox; cần người bản ngữ soát (đặc biệt th, id, hi, ar).
- Bản dịch do AI làm theo vi.json + en.json, có bảng thuật ngữ chung; nên nhờ người bản ngữ đọc lại trước khi
  phát hành rộng (ưu tiên ar, hi, th).
- Hiệu ứng trượt của menu/tooltip (`slide-in-from-left/right`) và mũi tên tooltip vẫn theo hướng vật lý khi RTL
  (chỉ là hiệu ứng). `Toggle` trong `ui/parts.tsx` không còn ai dùng, chưa đổi `translate-x` cho RTL.
- `mock-data.ts` (bản xem trước) giữ tên file mẫu tiếng Việt ("Sài Gòn đêm mưa — 4K") vì là dữ liệu.
- Các nhánh song song (2, 3, 5, 6) chưa commit lúc làm việc này: khi ghép, `pnpm lint` sẽ chỉ ra chuỗi Việt viết
  cứng mới và mã lỗi Rust mới cần chuyển sang khoá.
