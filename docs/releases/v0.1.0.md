Bản đầu tiên của UTD, cho Windows và macOS.
Tải file nhiều kết nối, tiếp tục khi rớt mạng; tải video/âm thanh YouTube, TikTok…; tải hàng loạt và cả kênh.
16 ngôn ngữ, tự tải công cụ media, tự cập nhật có kiểm chữ ký.

## Tải về

| Máy | File |
|---|---|
| Windows 10/11 64-bit | `UTD_0.1.0_x64-setup.exe` |
| macOS 11 trở lên (chip Apple và Intel) | `UTD_0.1.0_universal.dmg` |

Các file `.sig`, `.app.tar.gz` và `latest.json` dùng cho tự cập nhật, không cần tải. `SHA256SUMS.txt` chứa mã kiểm tra của mọi file.

## Có gì

- **Tải file**: chia nhiều kết nối, tự dò số kết nối (tối đa 16), tiếp tục sau khi rớt mạng hay tắt máy, kiểm SHA-256, không ghi đè file sẵn có.
- **Media**: dán link trang YouTube, TikTok, Facebook… rồi chọn chất lượng, tải MP4 hoặc M4A/MP3. Hình và tiếng tải song song rồi ghép MP4 ngay trong app, thường dưới 1 giây.
- **Tự tải công cụ**: lần đầu mở app tự tải yt-dlp, ffmpeg, deno từ nguồn chính chủ và kiểm SHA-256; yt-dlp tự cập nhật hằng ngày. Không cần cài gì thêm.
- **Tải hàng loạt**: dán nhiều link hoặc mẫu `[001-100]`; hàng đợi chung giới hạn số tải cùng lúc.
- **Tải cả kênh**: kênh TikTok, kênh hoặc playlist YouTube; lần sau chỉ tải video mới.
- **Download Guard**: file chạy được hoặc giả định dạng bị đưa vào khu cách ly; trên Windows file tải về được gắn Mark of the Web.
- **Tích hợp trình duyệt** Chrome, Edge, Brave, Firefox: chuột phải vào link, video, ảnh → *Tải bằng UTD*.
- **Giao diện 16 ngôn ngữ**, thanh tiêu đề riêng (Windows vẫn có Snap Layouts).
- **Tự cập nhật** qua trang Releases: chỉ cài gói có chữ ký của UTD, sao lưu lịch sử tải trước khi cập nhật.
- Không telemetry, không tài khoản, không cloud.

## Mở lần đầu

Bộ cài chưa ký số (chưa có chứng chỉ Windows và tài khoản Apple Developer) nên hệ điều hành cảnh báo một lần.

**Windows**: SmartScreen báo *Windows protected your PC* → bấm **More info** → **Run anyway**.

**macOS**: mở file `.dmg`, kéo **UTD** vào **Ứng dụng** (Applications), rồi:

1. Nhấp đúp **UTD**. macOS báo *"UTD" chưa được mở* → bấm **Xong** (Done), đừng bấm "Chuyển vào Thùng rác".
2. Mở **Cài đặt hệ thống** → **Quyền riêng tư & Bảo mật**, kéo xuống mục **Bảo mật** → bấm **Vẫn mở** (Open Anyway).
3. Hộp *Mở "UTD"?* hiện ra → bấm **Vẫn mở** (nút xanh là "Chuyển vào Thùng rác", đừng bấm).
4. Nhập mật khẩu máy (hoặc Touch ID). Từ lần sau UTD mở bình thường.

macOS 14 trở về trước có cách nhanh hơn: chuột phải vào UTD → **Mở** → **Mở**.

**Extension trình duyệt**: trong UTD mở **Cài đặt** → **Tích hợp trình duyệt** → **Bật tích hợp** → **Mở thư mục tiện ích**, rồi nạp thư mục `chromium` (Chrome/Edge/Brave, bật Developer mode → *Load unpacked*) hoặc `firefox/manifest.json` (Firefox, `about:debugging`). Chi tiết: [extensions/README.md](https://github.com/1Scout-Co/UTD/blob/v0.1.0/extensions/README.md).

## Chưa có

- Ký số bộ cài (cảnh báo như trên).
- Extension trên Chrome Web Store và Firefox Add-ons: hiện phải nạp thủ công.
- Gửi cookie đăng nhập từ trình duyệt (video cần đăng nhập chưa tải được), bắt download của trình duyệt.
- Giới hạn tốc độ, proxy.

### English

First release of UTD, an open-source download manager for Windows and macOS: multi-connection downloads that resume after network drops, YouTube/TikTok video and audio, batch and whole-channel downloads, 16 languages, signed auto-updates. No telemetry, no account.

Download `UTD_0.1.0_x64-setup.exe` (Windows 10/11 64-bit) or `UTD_0.1.0_universal.dmg` (macOS 11+, Apple silicon and Intel). The installers are not code-signed yet: on Windows click **More info → Run anyway**; on macOS drag UTD to Applications, open it once, then go to **System Settings → Privacy & Security → Open Anyway**.
